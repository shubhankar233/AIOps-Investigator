# Architecture Decision Records (ADR)

# AIOps Investigator

Architecture Decision Records (ADRs) document important technical decisions made during the development of AIOps Investigator.

Each ADR explains:

- The problem or context
- The available options
- The decision taken
- The rationale
- The consequences
- Future considerations

Documenting these decisions helps future contributors understand **why** the system was designed this way.
